# ☕ CoffeeDocs  
Un editor de documents minimalista amb temàtica de cafè, creat amb **HTML, CSS i JavaScript vanilla**.  
Inspirat en Google Docs, però amb una estètica càlida i un sistema de pàgines propi.

## ✨ Visió general
CoffeeDocs és un projecte educatiu on construeixo un editor web **des de zero**, sense frameworks, per aprendre:

- Arquitectura HTML professional  
- Maquetació CSS avançada  
- Editor amb `contenteditable`  
- Paginació dinàmica  
- Guardat i càrrega amb localStorage  
- Organització de projecte i bones pràctiques

---

## ☕ Estètica i filosofia
CoffeeDocs aposta per una experiència d’edició **càlida**, **minimalista** i **agradable**, amb:

- Tons crema, marrons i blancs trencats  
- Ombres suaus que simulen paper  
- Tipografies Poppins (UI) i Inter (text)  
- Icons SVG propis  
- Un “paper” centrat amb amplada fixa

## 🧱 Tecnologies utilitzades
- **HTML5** — estructura del document i pàgines  
- **CSS3** — estil del full, temes, layout i UI  
- **JavaScript vanilla** — editor, paginació, events, guardat i càrrega  
- **Git + GitHub** — control de versions  
- **VS Code** — Live Server, Prettier, ESLint, Auto Rename Tag, Path Intellisense

## 📝 Notes de desenvolupament
- L’ordre del projecte és **HTML → CSS → JS**  
- El JS es farà al final, quan la UI estigui estable  
- L’editor comença **sense placeholder**, com Google Docs  
- La paginació es farà detectant l’alçada del full  
- Tot el projecte és **vanilla**, sense frameworks
