# CoffeDocs
CoffeeDocs — Un editor de documents minimalista amb temàtica de cafè, creat amb HTML, CSS i JavaScript vanilla.   Inspirat en Google Docs, però amb una estètica càlida i un sistema de pàgines propi. Pensat com a projecte educatiu per aprendre a estructurar, maquetar i programar un editor web des de zero, sense frameworks.
